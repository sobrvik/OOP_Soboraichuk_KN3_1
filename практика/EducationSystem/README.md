# EducationSystem — навчальна практика з ООП

Тема: **Система управління навчальним закладом**.

## Сутності

- студент
- група
- факультет
- заняття
- репозиторій
- JSON-сховище

## Патерни

### Composite
Використано для структури:

```text
Факультет
 └── Група
     └── Студент
```

Класи: `Faculty`, `Group`, `Student`, інтерфейс `IUniversityComponent`.

### Visitor
Використано для обчислення рейтингу студентів без зміни класів структури.

Класи: `IUniversityVisitor`, `RatingVisitor`.

### Factory
Використано для створення різних типів занять.

Класи: `LessonFactory`, `Lecture`, `PracticeLesson`, `LabLesson`.

## ООП-принципи

- інкапсуляція через private-поля та валідацію
- наслідування через `Lesson`
- поліморфізм через `Conduct()`
- інтерфейси для слабкої звʼязаності
- generic repository `IRepository<T>`
- custom exception `DomainException`
- JSON-серіалізація через DTO
