# Сервіс замовлень їжі

## Короткий опис задачі
**Варіант:** Сервіс замовлень їжі (Menu / OrderLine).  
**Композиція:** `Order` містить колекцію `OrderLine`; кожен `OrderLine` посилається на `MenuItem`.  
**Дженерики:** 
- універсальний репозиторій `IRepository<T>` / `InMemoryRepository<T>` з базовими операціями `Add`, `Remove`, `Find`, `All`, `Where`;
- утиліта `Filter<T>(IEnumerable<T>, Predicate<T>)`; додатково продемонстровано `Max<T>(..., IComparer<T>)`.
**Контроль вхідних даних + власні винятки:** 
- `InvalidMenuItemException` (коли `Calories <= 0` або `Price <= 0` тощо),
- `NotFoundException` (пошук у репозиторії).
**Демонстрація:** у `Program.cs` — створення меню, замовлень, обчислення сум/середніх/максимумів, обробка помилок через `try-catch`.

## Що реалізовано
- Доменно: `MenuItem`, `OrderLine`, `Order`.
- Композиція: `Order` → `List<OrderLine>`.
- Обчислення:
  - загальна калорійність замовлення,
  - вегетаріанська частка у відсотках (по кількості одиниць),
  - середній чек по всіх замовленнях,
  - найкалорійніша позиція меню.
- Валідація та винятки: власні винятки при некоректних даних та пошуку.
- Дженерик-репозиторій + `Filter<T>`.
