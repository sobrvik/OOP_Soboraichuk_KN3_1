Тема: Абстракції та інтерфейси. Композиція.
Мета: Закріпити поняття інтерфейсів і абстрактних класів у C#, продемонструвати поліморфізм на прикладі бойових персонажів (Warrior, Archer), а також реалізувати композицію через клас Group, який містить колекцію персонажів і обчислює сумарну шкоду групи.

Опис виконання завдання

Проєкт реалізовано у вигляді консолного додатку на C#.
Головні компоненти:
IAttack — інтерфейс з методом int Attack().
Character — абстрактний клас, що реалізує IAttack і визначає загальні властивості Name та BaseDamage. Містить абстрактний метод Attack().
Warrior — клас-нащадок Character, реалізує Attack() як удар мечем (повертає BaseDamage).
Archer — клас-нащадок Character, реалізує Attack() як постріл зі збільшеною шкодою (BaseDamage * 2).
Group — клас, що містить список Character (композиція). Метод GroupAttack() викликає Attack() для кожного учасника і сумує шкоду.
Program.Main() — приклад створення персонажів, додавання до групи і виклику GroupAttack().
Реалізація демонструє:
інтерфейсну абстракцію (IAttack),
абстрактний клас із спільною логікою (Character),
поліморфізм при виклику Attack() для різних реалізацій,
композицію (клас Group містить Character).

Приклади запуску:

Іванов вдаряє мечем на 15 шкоди!
Сидоров випускає стрілу на 20 шкоди!
Сумарна шкода групи: 35
