# Лабораторна робота №25
## Тема
Інтеграція патернів (Factory Method, Singleton, Strategy, Observer)
## Мета
Розробити систему, що демонструє взаємодію між компонентами, які реалізують патерни Factory Method, Singleton, Strategy та Observer, а також перевірити коректність їхньої спільної роботи.
## Опис роботи
У програмі реалізовано систему обробки даних, яка демонструє інтеграцію декількох патернів проєктування.
### Factory Method
Використовується для створення логерів.
```
LoggerFactory
├── ConsoleLoggerFactory
└── FileLoggerFactory
```
### Singleton
Клас LoggerManager реалізує патерн Singleton і забезпечує єдину точку доступу до логера.
### Strategy
Дозволяє змінювати алгоритм обробки даних під час виконання програми.
```
IDataProcessorStrategy
├── EncryptDataStrategy
└── CompressDataStrategy
```
### Observer
Клас ProcessingLoggerObserver підписується на подію DataProcessed, яка генерується класом DataPublisher.
## Реалізовані сценарії
### Сценарій 1 — Повна інтеграція
1. Ініціалізується LoggerManager з ConsoleLoggerFactory
2. Створюється DataContext з EncryptDataStrategy
3. Створюється DataPublisher
4. Observer підписується на подію
5. Дані обробляються та публікуються
Результат: повідомлення логуються у консоль.
### Сценарій 2 — Динамічна зміна логера
Після першої обробки змінюється фабрика логера.
```
ConsoleLoggerFactory → FileLoggerFactory
```
Результат: логування починає записуватись у файл log.txt.
### Сценарій 3 — Динамічна зміна стратегії
Після першої обробки змінюється стратегія обробки даних.
```
EncryptDataStrategy → CompressDataStrategy
```
Результат: дані обробляються новим алгоритмом.

## Висновок
У ході лабораторної роботи було реалізовано інтеграцію патернів Factory Method, Singleton, Strategy та Observer. Було продемонстровано їх спільну роботу та можливість динамічної зміни логера і алгоритму обробки даних під час виконання програми.
