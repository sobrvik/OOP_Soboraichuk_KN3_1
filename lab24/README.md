# Лабораторна робота №24

## Тема
Strategy + Observer: динамічна підстановка алгоритмів та сповіщення про результати.

## Мета
Застосувати патерни **Strategy** та **Observer** для створення системи обробки числових даних з можливістю зміни алгоритмів під час виконання та автоматичного сповіщення підписників про результат.

## Опис роботи
У програмі реалізовано систему обробки чисел.

### Патерн Strategy
Патерн **Strategy** дозволяє змінювати алгоритм обробки числа під час виконання програми.

Реалізовані стратегії:
- `SquareOperationStrategy` — обчислення квадрата числа
- `CubeOperationStrategy` — обчислення куба числа
- `SquareRootOperationStrategy` — обчислення квадратного кореня

Клас `NumericProcessor` використовує поточну стратегію для обробки числа.

### Патерн Observer
Патерн **Observer** реалізовано через події C#.

Клас `ResultPublisher` генерує подію `Action<double, string> ResultCalculated`.

Підписники на подію:
- `ConsoleLoggerObserver` — виводить результат у консоль
- `HistoryLoggerObserver` — зберігає історію результатів
- `ThresholdNotifierObserver` — повідомляє, якщо результат перевищує поріг

## Демонстрація роботи
У методі `Main`:
1. Створюється `NumericProcessor`
2. Створюється `ResultPublisher`
3. Підписуються спостерігачі
4. Встановлюються різні стратегії
5. Виконується обробка чисел
6. Публікується результат через подію

## Висновок
У роботі реалізовано патерни **Strategy** та **Observer**, що дозволило створити гнучку систему обробки числових даних. Strategy забезпечує зміну алгоритму під час виконання, а Observer дозволяє автоматично сповіщати різні компоненти про результат обчислення.
